# 账户切换后自选列表稳定性修复计划

## 目标

保证同一账户在快速添加大量股票、切换到其他账户、再切回并刷新后，自选列表不会因并发写入而损坏、丢失或归零；不同账户仍保持工作区隔离。

## 工作包

1. 复现并固化契约：用同一账户并发添加大量自选，再切换账户并切回，验证 API 返回数量、磁盘文件和用户目录均正确。
2. 后端持久化：为自选 Parquet 读改写增加进程内互斥、跨进程文件锁和原子替换，避免部分写入、并发覆盖和损坏文件；保留现有文件格式及接口。
3. 前端身份边界：检查切换时查询/突变缓存生命周期，确保旧账户请求不能回填新账户的全局查询键；将自选相关本地设置按账户隔离或在切换时清理。
4. 验证：运行回归测试、受影响后端测试、前端构建与差异检查，并进行本地 API 切换流程冒烟。

## 兼容与回滚

- 不改变 API 响应结构和 Parquet 字段；已有自选文件可直接读取。
- 写入先生成同目录临时文件并原子替换；失败时保留原文件。
- 若检测到历史损坏文件，返回明确错误而不是静默伪造空列表；通过备份文件可恢复。
