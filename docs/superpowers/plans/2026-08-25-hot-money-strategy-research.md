# 游资风格策略研究与回测计划

## 目标

在不改变现有回测成交约束和策略接口的前提下，修复已确认的涨停幅度特征契约问题，审查现有内置策略，并用同一套 A 股日线、资金、费用和滑点口径筛选游资风格候选。只有在样本外仍有可解释结果的候选才进入策略库；否则只保留研究结论，不把样本内收益包装成可实盘策略。

## 工作包

1. **回测契约修复**
   - 为 `near_limit_up` 的 `price_limit_pct` 特征增加可用性回归测试。
   - 修复矩阵特征可用性判断，保持旧策略和 ETF/股票字段行为兼容。
   - 涨停相关阈值统一使用未复权 `raw_close` 计算的 `raw_change_pct`，避免除权日把复权涨跌幅与涨停规则混用。

2. **现有策略基准与参数筛选**
   - 用本地最新完整日线区间建立基准，固定初始资金、次日开盘成交、手续费、印花税、滑点、持仓数和 T+1 约束。
   - 将时间拆为样本内与样本外，筛选 `risk_capped_reversal`、`n_day_low_reversal`、`strong_open` 等已有策略的稳健参数；记录交易数、收益、最大回撤、Sharpe 和样本覆盖。

3. **游资风格候选**
   - 仅使用矩阵引擎已支持且可追溯的特征，设计“放量突破、首板回踩/反包、龙头回撤再起”候选。
   - 先写信号边界测试，再实现统一 `META`、执行后端、止损和最长持有天数；不实现无上限加仓的马丁格尔。
   - 新候选标记为研究型，未通过更长样本和历史 ST 状态验证前不宣称可实盘。

4. **验证与交付**
   - 运行定向测试、后端完整测试、前端构建和策略回测。
   - 仅提交本次策略/回测相关文件；报告真实数据覆盖、成本假设、样本内/样本外结果、未通过候选和上线前剩余风险。

## 回滚

策略文件为独立内置插件，回滚时恢复本次新增/修改文件即可；不修改生产数据文件和数据库结构。若新候选样本外未通过，则不在默认策略列表中启用，只保留测试和研究报告。
